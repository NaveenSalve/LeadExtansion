# 📍 Leads Extractor — Naveen Salve

## Install Kaise Karein (3 Steps)

1. **ZIP extract karo** — ek permanent folder mein (Downloads folder mein mat rakho)

2. **Chrome mein jaao:**  
   `chrome://extensions` → **Developer Mode ON** karo (top-right toggle)

3. **"Load unpacked"** click karo → extracted folder select karo → Done! ✅

---

## Use Kaise Karein

1. **Google Maps** ya **Bing Maps** pe jaao
2. Koi business search karo (e.g. `dentists Delhi`)
3. Results load hone do — scroll karo
4. Extension icon click karo → **Start Extraction** button dabao
5. Filters lagao → **CSV Download Karo**

---

## Filter Options

| Filter | Kya Karta Hai |
|--------|--------------|
| ✅ Duplicates Hatao | Same naam ke duplicate leads remove karta hai |
| No Website Only | Sirf woh leads jo online nahi hain — best for outreach |
| Phone wale Only | Sirf woh leads jinke paas phone number hai |
| Low Rating (≤3★) | 3 star ya kam wale business — improvement services ke liye |

---

## Tips

- Scroll karke zyada results load karo, phir dobara Extract karo — data accumulate hoga
- Google Maps + Bing Places dono se nikaalo, zyada coverage milegi
- No Website filter = sabse valuable leads for web design/digital marketing services
